# CodSoft Data Analytics Internship - Task 3

## Project Overview
This repository contains the code and deliverables for Task 3 of the Data Analytics Internship at CodSoft. This task emphasizes data visualization and communication of insights through a multi-plot analytical dashboard.

## Dataset Information
* **Dataset Used:** Cleaned Online Food Delivery Dataset
* **Tool Used:** Python, Matplotlib, Seaborn, Pandas

## Key Steps & Implementation
* Designed a multi-plot visualization layout (2x2 grid dashboard).
* Created customized visual elements including count plots, distribution histograms, and categorical breakdowns.
* Highlighted customer behavioral metrics, age distributions, and feedback proportions.
* Formatted charts with professional titles, axis labels, and color palettes to enhance readability.

## How to Run
1. Clone the repository and navigate to the project directory.
2. Ensure the required visualization libraries are installed (`matplotlib`, `seaborn`).
3. Open the Jupyter Notebook (`.ipynb`) file and run the dashboard generation cells.
